Datos

Los datos se guardan automáticamente en este navegador. Descarga un respaldo para pasarlos a otra computadora o para no perderlos.

Descargar respaldo

Guarda un archivo JSON con alumnos, profesionales, cuentas, citas y mensajes.

Cargar respaldo

Selecciona un archivo JSON descargado antes. Reemplaza los datos actuales.
